Connect to ESP32

WebSocket

Enter the WebSocket URL from your ESP32 firmware, e.g. ws://192.168.1.120:81/. The firmware must send JSON with the fields below. Note: a GitHub Pages HTTPS page may block insecure ws://; for public HTTPS hosting you may need a secure WebSocket endpoint, or use a local dashboard served by the ESP32.

Expected JSON example: {"ecgBpm":72,"pulseBpm":74,"spo2":98,"temperatureC":36.6,"ecg":[2040,2050,2070],"leadOff":false,"ecgValid":true,"maxValid":true,"tempValid":true}. Send one JSON object per WebSocket message. Omit fields that are unavailable rather than inventing readings.
