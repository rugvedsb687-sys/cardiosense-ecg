Connect to your ESP32

Local network

Enter the WebSocket address served by your ESP32. Example format: ws://192.168.1.120:81/. Your firmware must implement the same JSON message format described below.

Expected JSON: {"bpm":72,"ecg":2048,"leadOff":false,"valid":true}. The firmware should send one JSON object per WebSocket message. ECG can also be an array of recent samples: {"bpm":72,"ecg":[2040,2050,2070],"leadOff":false,"valid":true}.
